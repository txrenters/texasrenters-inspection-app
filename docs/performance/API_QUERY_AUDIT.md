# API query audit

Audited 2026-07-21 against the NestJS REST API and the development Supabase PostgreSQL database. Runtime figures include authorization and instrumentation. Payloads are uncompressed JSON. The database is in Canada Central while this measurement client is in the Philippines, so duration is dominated by network distance.

The response reductions are real, but the remaining approximately 250-300 ms per database round trip is regional latency. Multi-query pages such as the technician list and mobile dashboard remain visibly affected even when independent reads run concurrently. The compact mobile context query is covered by authorization and single-read regression tests; runtime payload measurement was skipped honestly because the configured benchmark technician has no current assignment.

## Full-row and relation audit

Application-facing reads found with oversized or full selections included admin property detail, inspection detail, technician detail, authentication membership loading, floor plans, technician uploads/findings/dashboard, legacy Propertyware catalog routes, Propertyware sync runs/errors, and technician room baselines. These paths now use screen-specific `select` objects. Inspection creation now returns only its new ID instead of re-reading a complete nested detail graph. Internal synchronization and write-verification reads were left alone where the complete record is required.

No new index was added in this pass. Existing composite indexes cover organization/status/schedule inspection pages, building-active units, unit-active leases, technician assignments, findings by inspection/review status, sync errors by run/entity, audit events by entity/time, chronological sync runs, and property-area ordering. `EXPLAIN` continued to show an index scan for active properties; the small development data set used inexpensive sorts for scheduled inspections and latest sync. Case-insensitive `contains` search remains a future production-plan candidate; adding a trigram index without production-sized evidence was not justified.
